
# GRC Vendor Compliance & Evidence Tracker

A dynamic, automated GRC template built in Microsoft Excel to streamline third-party risk management and vendor lifecycle monitoring.

## 🚀 Features
* *Automated Expiry Tracking:* Uses the TODAY() function to calculate real-time days remaining until vendor assessment expiration.
* *Conditional Compliance Alerts:* Automatically flags upcoming expirations using logical IF statements (URGENT:RENEW vs. COMPLIANT).
* *Executive KPI Summary Dashboard:* Dynamic metrics block tracking *Total Vendors* (COUNTA) and *Urgent Renewals* (COUNTIF) at a glance.
* *Standardized Layout:* Clean, professional headers tracking Vendor Name, Assessment Type, Status, Expiry Dates, and Days Remaining.
